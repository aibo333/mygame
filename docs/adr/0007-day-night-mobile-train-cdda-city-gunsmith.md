# ADR-0007: 晝夜移動防線遠征 × CDDA 街區生成 × 槍匠養成 × 冷峻戰術動漫風格

- **狀態**：已採納（Accepted）
- **日期**：2026-11-26
- **修訂／演進**：修訂 [ADR-0005](0005-gameplay-pivot-train-extraction-horde-and-external-assets.md) 的「固定月台停靠 × 8 分鐘短局撤離」循環，保留單人直控、碼圖分離管線與 [ADR-0006](0006-uncharted-waters-inspired-train-carriage-customization.md) 之列車改裝體系，並正式定錨新版長線核心玩法與地圖／UI／養成規格。

## 背景與決策（Context & Decision）

在完成 Phase 1～5 原型驗證後，我們將核心遊戲體驗重新聚焦於「**裝甲列車如何在隨機都市中建立移動防線並抵禦屍潮圍攻**」的戰術張力，做出以下五項定錨決策：

1. **核心循環轉為「多日晝夜循環 × 白天鐵軌機動選點 × 夜間陣地防守」**：
   - 列車駛入隨機生成的都市街區（Sector）後，不再永久固定於北側邊緣月台，而是**在白天可沿貫穿街區的鐵軌前後移動與煞停**。
   - 玩家的核心任務是偵查地形，將列車停靠在易守難攻的位置，並利用地面臨時工事（沙包、拒馬、地雷、固定砲台與照明）構築防線。
   - 白天街區分佈零散遊蕩怪物；入夜後鍋爐鎖定供電給防禦系統，成群怪物會主動圍攻列車當前停靠位置，且同圖停留天數越久怪物越強。

2. **血月雙軌＋隨機事件機制（Blood Moon Gauge `0～100`）**：
   - 血月觸發採**時間累積 ＋ 行為累積（高噪音、啟動大型設施、清除巢穴與精英）**並行，確保玩家有一定可預測性與風險掌控感。
   - 搭配地圖隨機異常或干預事件增減血月值，避免節奏過度死板；黃昏檢定達標即預警並於入夜進入血月時刻。

3. **長期堅守誘因（留守 vs 離圖張力）**：
   - **下限門檻（推力）**：進入新圖時面臨離站燃料需求或鐵軌路障清理門檻，保底經歷至少 1～2 個晝夜交替。
   - **大型固定設施（拉力 1）**：需將列車停靠鄰近供電／接駁，隨停留天數提供階梯暴增的高階產出，離開地圖即斷線放棄；地面臨時工事亦不隨車帶走，形成陣地沉沒成本。
   - **高階戰利品分層（拉力 2）**：白天遊蕩怪僅提供維持消耗的基礎補給；稀有藍圖與改裝核心鎖定於多日設施、夜間圍攻精英與血月掉落。

4. **永久成長優先主軸：槍匠系統（Gunsmith System）先行**：
   - 優先於人物天賦與車廂藍圖實作，以現有 3 把武器（M4A1-S / AK-47 / Desert Eagle）為基礎擴展槍械解鎖、基礎強化與戰術配件槽位（槍口／彈匣／下掛照明），並與晝夜視野、噪音警戒圈及血月值累積直接聯動。

5. **CDDA 式五步隨機街區管線（從民防住家建築起步）與《少女前線2：追放》冷峻畫風**：
   - 隨機街區採參考《Cataclysm: DDA》的五步管線：**① Nested Room Block 庫 → ② 建築配方與拓撲 → ③ Overmap 道路網與貫穿鐵軌廊道 → ④ 沿街朝向對齊 → ⑤ 全局廢墟化濾鏡**（World-Space 髒污 Shader ＋ 程式翻倒家具 ＋ `Decal` 貼花）。
   - 美術與 UI 全面轉向**《少女前線2：追放》冷峻戰術動漫風格**：深石板黑底、1px 銳利鋼灰框線、非對稱工業琥珀／全息青色飾條與清晰數據標籤，取代早期暖棕圓角與卡通圖示。

## 技術與實作影響（Consequences）

- **UI 統一設計系統**：建立共用 `TacticalTheme` 模組規範全介面色票、字階、邊框與按鈕狀態，確保開發期原型與後續新增的槍匠／晝夜／血月 HUD 風格一致。
- **建築與格網對齊**：外圍 Overmap／道路維持 `3.2m` 格距基準，民防住家建築內部採用 `1.6m` 子格網與薄邊緣牆體設計，並復用 `ArmoredTrainBase` 已驗證之自動切頂透視（Roof Cutaway）機制讓玩家可進入建築室內搜刮。
- **分階段推進**：依序執行 Milestone 0（文件與資產規格）→ UI 冷峻科技感改版 → Milestone 1（CDDA 五步街區＋鐵軌）→ Milestone 2（晝夜與雙向行駛）→ Milestone 3（雙層怪物與血月）→ Milestone 4（設施、陣地維護與跨圖）→ Milestone 5（槍匠永久養成）。
