# ADR-0004: 美術與視角全面轉型 — Blue Archive 風格 3D 小人 × LOL 固定俯瞰視角 × 末日廢墟 × 甲鐵城裝甲列車基地

- **狀態**：已採納（Accepted）
- **日期**：2026-11-24
- **取代／修訂**：取代 ADR-0001（中世紀戰意設定）與 ADR-0003 中的肩後 TPS 視角配置；舊版中世紀 Godot 4 原型已完整封存於 Git Tag `v0.3-medieval-godot-prototype`。

## 背景（Context）

在完成 Godot 4 遷移後，初期採用程式化幾何體（方塊／膠囊）與中世紀攻城主題驗證了基本流程，但視覺質感不足導致開發動力受限，且肩後 TPS 視角對 3D 角色精細模型、近距離骨架變形與防穿牆鏡頭的製作成本極高。

為建立具辨識度且適合單人／小型團隊長期推進的高質感美術管線，團隊決定先確立基礎美術與視角標準：

## 決策（Decision）

1. **角色風格與動作規格（Blue Archive 風格 3D SD 美少女小人）**：
   - 採用 2.5～2.8 頭身日式動漫 SD 比例、頭頂發光光環（Halo）、高解析動漫臉部 UV 貼圖與 Godot 4 賽璐璐著色器（Cel-Shading + 描邊）。
   - 首批建構 3 名完整綁骨（Armature）的 `.glb` 戰術小隊角色：
     - **白羽 玲奈（Reina）**：銀白高馬尾／突擊步槍隊長（青藍光環）
     - **蒼井 千紗（Chisa）**：藍黑短髮護目鏡／衝鋒槍工兵（琥珀齒輪光環）
     - **星野 莉莉（Lily）**：暖金雙馬尾／重型霰彈先鋒（緋紅準心光環）
   - 動作精簡為高性價比核心四式（另附 `idle` 待機）：**`walk`（走路）**、**`shoot`（開槍）**、**`interact`（摸東摸西：開鎖／製作）**、**`roll`（戰術翻滾）**。
   - 保留標準化 `.glb` 角色匯入介面，未來可直接無痛替換為 VRoid Studio 或自製 Blender 模型。

2. **鏡頭系統（取消 TPS，改為 LOL 固定俯瞰視角）**：
   - 移除 `SpringArm3D` 肩後 TPS 與滑鼠鎖定機制。
   - 改採類似《英雄聯盟（LoL）》的固定俯角等距透視攝影機（約 52° 俯角、窄視野減少透視變形），支援 `Y` 鍵切換鎖定／自由平移、滑鼠中鍵拖曳／螢幕邊緣移鏡、`C`/`Home` 瞬間回中與滾輪縮放，大幅降低 3D 動作與綁骨視覺門檻。

3. **場景與基地核心視覺（《少女前線 2：追放》廢墟 × 《甲鐵城的卡巴內利》裝甲列車）**：
   - 場景採黃昏電影感冷暖對比光影（冷灰藍殘垣斷壁、高架橋斷面、廢棄車輛與水泥掩體 ＋ 暖橘夕陽與列車探照燈／爐心火光）。
   - 核心基地為一台具重裝鉚釘鋼板、楔形破障排障器、發光蒸氣爐心、雙煙囪與工作坊車廂的 **甲鐵城風格裝甲列車（`.glb`）**，停駐於貫穿廢墟大道的鐵軌上。

4. **自動化 3D 美術產線（Blender Headless + Python）**：
   - 所有基礎 `.glb` 角色、列車與廢墟模組與貼圖皆由 `tools/art_pipeline/` 腳本可重現生成，方便快速微調比例、材質、骨架與動畫並直接輸出至 Godot `assets/`。

## 影響（Consequences）

- **正面**：畫面整體辨識度與開發熱情顯著提升；固定俯瞰視角讓 4 組動作即可支撐流暢操作；模組化 `.glb` 資產易於替換升級。
- **後續**：待基礎美術、角色動作與場景探索／互動手感定案後，再逐步接回戰鬥波次、搜刮／製作與裝甲列車基地養成循環。
