# ADR-0001: 從純自動戰鬥轉向《戰意》式「武將手操 ＋ 兵團指揮」

- **狀態**：已採納（Accepted）
- **日期**：2026-11-23

## 背景（Context）

在 Phase 1 初期（Commit `b0d167c`），我們實作了基於 GDD v0.1 的「3 人小隊純自動戰鬥 ＋ 戰中切換 3 種戰術陣型」原型並實際試玩。

試玩後發現：純自動戰鬥搭配 4 秒冷卻的陣型切換，玩家在戰鬥中的操作介入感與即時回饋不足，核心體驗不夠有趣。

## 決策（Decision）

退回規格重新設計為 **GDD v0.2**，改採參考 **《戰意》（Conqueror's Blade）** 的核心玩法：
1. **2.5D 俯視角動作操控**：玩家直接透過 `WASD`、滑鼠瞄準揮擊／技能與 `Space` 翻滾操控自己的武將。
2. **即時兵團指揮**：玩家同時率領 1 支 8～16 人的單一兵種兵團（刀盾／長槍／長弓），以 `C`（跟隨）、`X`（定點列陣）、`V`（自由進攻）、`F`（兵團特技）與 `1/2`（陣型切換）指揮軍團作戰。
3. **保留 Roguelike 守城循環與純 TS 核心分層**：維持 `Vite + React + TypeScript + Phaser 3` 與 `src/core/` 解耦架構，將玩家操作抽象為 `PlayerInput`，確保未來仍可擴展至多人協防。

## 影響（Consequences）

- **正面**：大幅提升戰鬥中的玩家能動性、打擊感與「武將破陣 ＋ 兵團扛線」的雙層策略樂趣。
- **代價**：需重構 `src/core/combat/`、`src/game/` 與 `src/ui/` 以支援 2.5D 自由移動、近戰扇形命中判定、兵團陣型插槽（Formation Slots）與士兵群體碰撞。既有 v0.1 原型保留於 Git Commit `b0d167c` 可隨時查閱。
